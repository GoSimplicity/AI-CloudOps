- 真实 HTTP 验证登录、刷新、注销撤销、分类持久化及 URL ID/操作者防伪造；只读角色越权 403、撤权立即生效、冻结/删除拒绝旧令牌。AI 65 项权限目录与真实 HTTP/WebSocket 路由核对，工具、执行、确认、通知分别授权。
- 完整工单由分类→表单→发布流程→模板→草稿→提交→审批完成，评论、流转、审计及清理通过。最终模板创建额外检查分类/模板来源快照；同源 HTTP、RBAC、完整工单已在最终 Go 镜像全部复验通过。
- 生产前端 15 项只读场景通过：首轮13项通过、2项因测试合同过时失败；修正缺ID错误断言与hash导航偏好重载前置后，定向2项通过。58 个已注册组件中 56 个静态入口直接走查；两个动态 SSH 入口有独立真实协议测试。本轮守卫未放行任何业务写入/模型/通知/云动作，实际503为0；只注入预期的过期列表/刷新401。详见 Web 仓库 `docs/release/production-acceptance-1.0.md`。明暗主题、移动布局、认证和会话隔离均执行实际浏览器检查，业务创建与编辑另有隔离用例。
- SSH 使用本机独立 OpenSSH 容器及唯一密钥、严格主机校验；本地和云资源两条网关均执行真实 PTY 算术、窗口尺寸、Ctrl-C、关闭会话。浏览器没有重复 WebSocket，访问令牌不进入 URL，普通资产 JSON 不返回私钥/密码。未连接线上主机。
- Kubernetes 使用本机 owned kind 1.35.8：真实资源创建/查询/扩容/日志/Pod WebSocket exec、SSA 创建更新及冲突不抢占、更新副本未就绪的 rollout 反例与修复均通过。来源配置不静默回退，模型上下文副本脱敏；高风险操作必须通过所有者绑定且只能消费一次的审批。
- 定时任务使用真实独立 MySQL/Redis：进入 Running 后仅 SIGKILL 自有临时 worker，Redis 重投递、租约过期后完成，最终镜像复验在 97 秒完成并清理独立项目。恢复时间为本轮观测，不承诺固定 SLA 或恰好一次执行。
