# Azure 只读计算客户端

> 当前口径（2026-10-30）：本页保留分阶段交付与隔离测试证据；完整能力状态及未验边界见[当前完成度矩阵](readiness-current.md)。不以早期“未接线”描述覆盖后续实现，也不将隔离测试视作真实云验收。

本阶段新增官方 ARM Compute 客户端。调用方须显式提供 tenant、client、client secret、subscription 与地域；不读取宿主机环境凭据、文件或托管身份。仅允许固定公有云端点的GET请求，关闭SDK的资源提供者自动注册；分页地址受限于可信主机、订阅及地域。

指定VM UUID必须完整匹配，缺失/重复/跨地域或后续页错误不返回部分清单；无法证明订阅资源范围完整时，客户端拒绝无ID查询，共享入口须继续禁止全量及无ID同步。列表API不提供的状态、容量与费用保持未知。账户工厂、完整服务主体凭据及前端指定ID同步已接入；无ID/全量限制仍由服务端和前端共同执行。

隔离内存HTTP传输验证真实SDK身份和签名、分页、ID、取消及日志保密；本地快照race通过，govulncheck 未发现可达漏洞，未连接真实Azure或生产环境。
