# 云资源地域同步合同

每个账户地域以数据库租约和令牌隔离同步；云端查询在数据库事务外完成，写入时重新校验租约、账户凭据版本及地域状态。资源、绑定、变更记录和地域成功历史在同一事务提交，失败回滚该地域；其他地域的结果分别报告。处理中的请求绑定可信登录用户，不能由请求体覆盖审计操作人或路径资源 ID。

AWS 和腾讯云临时凭据可全量同步。华为云、Azure、GCP 因无法证明读取权限覆盖整个范围，只支持指定实例 ID 的增量同步；未提供 ID 或请求全量时拒绝。临时凭据有效期内的取消和超时也不得绕过提交检查。

每个地域返回状态、历史编号与 `retry_safe`。提交回执丢失、审计不可用或进程崩溃后过期的执行中历史必须按结果不确定处理，先核对实际资源和历史，不应自动重试。旧的汇总历史为兼容保留，地域历史是判断每个地域结果的依据。

启动迁移会新增地域租约表和历史字段。升级需先停止旧版本同步工作进程、备份并确认迁移成功，再启动相同版本；不要混跑不遵守租约的旧版本。本阶段未连接真实云，也未部署或迁移生产环境。
