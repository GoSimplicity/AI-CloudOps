# 创建时选择停用状态

Cron 任务和云账户均支持“先保存停用配置，再明确启用”。这是正常业务能力，不是测试专用开关，也不改变既有执行、SDK、RBAC 或本地命令限制。

## 请求与默认兼容

`POST /api/cron/job/create` 与 `POST /api/tree/cloud/account/create` 新增可选 `status`：

| 输入 | 结果 |
| --- | --- |
| 不提供或 null | 沿用原行为，保存为启用 1 |
| 1 | 保存为启用 |
| 2 | 从首次持久化开始即为停用 |
| 0、3、负数、超大整数或非整数/字符串 | 拒绝，不写入 |

HTTP 绑定和服务层分别校验，不能用显式 0 借 GORM 默认值静默变成启用。创建表单默认仍选启用，可明确选择“停用（仅保存）”；取消并重新打开恢复默认。编辑既有配置不复用初始状态字段，启停继续使用已有独立动作和权限。

创建 Cron 只保存，启用任务由正常调度器按表达式处理；停用任务不进入调度或手动执行。云账户创建不自动验证云身份或同步资源，停用状态从首次提交开始生效；地域保存不代表真实云授权已确认。凭据仍加密保存、普通读接口不回显。

示意 HTTP 任务字段：

```json
{
  "name": "待核对的 HTTP 配置",
  "job_type": 3,
  "status": 2,
  "schedule": "@every 1h",
  "http_method": "GET",
  "http_url": "http://127.0.0.1:9/fixture",
  "max_retry": 0
}
```

上例是停用配置，不要求或触发对该 URL 的请求。

## HTTP 地址校验一致性

创建与编辑共用 HTTP/HTTPS URL 规则。合法 `http://127.0.0.1:9`、HTTPS 与 IPv6 地址不再被旧前端 URL 正则误拒绝；服务端也验证协议、非空 host 和有效端口。非 HTTP 协议、空 host、非法端口、空格/控制字符及反斜杠形式均拒绝，不通过浏览器 URL 解析器自动去掉控制符再发送另一个原始字符串。校验本身不请求网络，错误不回显完整地址。

## 验证边界

- Go 表驱动测试覆盖 HTTP 绑定与服务层的缺省/启用/停用及非法状态，真实 SQLite HTTP 链路读回停用值，创建路径没有队列或云调用；URL 的创建/编辑与实际 HTTP 持久化拒绝路径均覆盖。
- Vue 真实控件回归验证发出 status=2、默认重置、凭据不回填、创建不隐式验证/同步，以及前后端对应的 HTTP 地址语法边界。
- 三仓业务浏览器增加始终停用的 HTTP 创建→编辑→读回→删除，以及阿里/AWS/腾讯 fake 凭据账户 CRUD；均阻止启用、任务执行或云 SDK 请求。精确五例合同见[浏览器 CI](business-browser-ci.md)。

当前本地验证不启动已有服务，不访问真实云、模型、通知或 SSH。真实五例浏览器执行须由匹配源码版本的新隔离 CI 完成，不以单测、discovery 或旧两例结果代替。
