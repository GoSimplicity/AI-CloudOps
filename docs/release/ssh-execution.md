# SSH 执行边界验收

SSH 客户端保留既有 `Connect` 与 `Run` 入口，新增接收请求上下文的 `ConnectContext` 与 `RunContext`。旧 `Run` 使用 5 分钟默认执行期限，连接默认 10 秒，显式请求的更短期限优先

上下文取消覆盖 TCP 连接、SSH 握手、创建执行会话、发送 exec 请求及等待输出。取消通过关闭该 SSH 传输实现，因此同一连接上的其他会话也会被关闭；调用方应将批任务与交互终端使用的连接分开。不得在取消后继续复用该传输

标准输出和错误输出共享带锁缓冲，最多保留 65408 字节，超限部分继续消费并返回截断标记，满足 `io.Writer` 消费契约并控制 MySQL TEXT 持久化大小。截断处丢弃不完整 UTF-8 字节，避免中文被切半。客户端不记录命令内容与原始输出

已执行本机回环 SSH 协议验收：动态生成测试密钥及独立 `known_hosts`，覆盖密码/私钥认证、可信主机成功、未知主机拒绝、错误密码拒绝、正常执行、远端退出错误保留部分输出、大输出限额、已开始执行后的取消、会话建立阻塞取消及握手阻塞取消。测试服务及连接随测试结束清理，没有连接生产或真实远端

```sh
GOTOOLCHAIN=auto go test -race -tags=smoke ./pkg/ssh ./internal/tree/ssh
GOTOOLCHAIN=auto go vet ./pkg/ssh/... ./internal/tree/ssh
```

SSH 协议关闭连接不保证远端已脱离会话的后台进程被终止。对需要强制远端进程树清理或事务恢复的任务，应使用具备任务身份、租约及取消协议的远端执行代理。真实远端的认证、系统 shell 行为与业务命令尚未验收
