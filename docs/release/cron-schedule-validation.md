# Cron 表达式与恢复

创建、更新和启用任务均使用与 Asynq v0.22 一致的 robfig 标准五字段及 descriptor 解析器；支持 `@every` 和 `TZ=`/`CRON_TZ=`。无时区前缀时按 Asynq 默认 UTC 计算，预览转换为服务器本地时区展示。历史非法表达式需先修正才能启用。

配置替换前先校验，非法表达式不撤销已有调度；意外注册失败时尝试恢复旧条目，恢复失败明确记录。为避免双条目重叠，撤旧到注册新条目之间存在短暂空窗，已入队任务不被撤回。

首次数据库加载失败按1、2、4秒递增退避，最长30秒，取消时立即退出；恢复成功后继续30秒周期同步。调度器提供线程安全的运行/就绪、连续失败次数和最近成功时间，供就绪检查使用。

验证：scheduler/service/task race 和真实 Gin+SQLite smoke，含失败恢复、取消、无效表达式及实际 Asynq 注册合同。CI smoke已覆盖 service。
