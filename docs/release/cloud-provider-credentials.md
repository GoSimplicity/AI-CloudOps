# Azure 和 GCP 账户凭据

Azure 服务主体及 GCP service_account 使用按厂商验证的完整凭据对象，整体加密存储并随账户版本CAS轮换；普通列表、详情、日志及审计不回显。旧厂商 AK/SK 仍按原合同读取，迁移已有 Azure/GCP 记录时同事务清除不再使用的旧密文。GCP仅接受固定可信 token_uri，不使用宿主环境或元数据凭据。

旧数据库须先停写、备份并演练新 `provider_credentials` 列迁移，再统一升级实例；不允许旧实例继续写新类型账户。Azure/GCP客户端仅允许指定实例增量，全量/无ID同步尚需证明授权覆盖。前端字段及同步入口随独立阶段交付。

隔离MySQL验证旧表迁移、密文兼容、完整组轮换、冲突及回滚；真实Gin和SDK内存传输验证凭据不回显。未连接真实云或生产环境。
