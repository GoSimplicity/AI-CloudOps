# HTTP 定时任务超时

HTTP 任务的总期限由任务 `timeout`（秒）控制，未设置时为 30 秒；调用方的更早取消或截止时间仍然生效。HTTP 客户端不再叠加固定 30 秒的总超时，网络连接与 TLS 阶段继续使用 Go 默认 Transport 的超时配置。

任务 URL 可能包含敏感查询参数，执行日志不记录完整 URL；传输和读取错误只返回安全类型，取消和截止保留 `errors.Is` 语义。响应正文和截断行为沿用原有合同。

验证：`go test -race ./internal/cron/handler` 覆盖默认及 120 秒配置的请求上下文期限、取消传播与 URL/错误隐私；已有 smoke 验证真实本地 HTTP 返回和输出限制。
