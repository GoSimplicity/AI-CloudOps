# 内置 Cron 调度合同

值班历史、Kubernetes 状态检查和 Prometheus 配置刷新使用统一的真实单次执行路径，手动触发和定时执行共享任务租约、状态与日志。集群检查分页读取全部集群并传播部分失败；值班记录失败也不再报告成功。数据库启停和调度表达式会定期重载，最多约30秒生效，执行前再次读取状态；停止会取消并等待正在运行的回调。

**升级行为变化**：既有内置任务的数据库 `schedule` 与启停状态不再被初始化覆盖，升级后这些表达式将实际生效。旧版实际使用固定循环，可能与数据库中的历史默认表达式不同；部署方应先审阅现有记录并调整期望频率。新库默认分别为 `@every 10s`、`@every 60s`、`@every 15s`。旧 `prometheus.refresh_cron` 不再覆盖数据库时间表。

调度配置加载失败时 `/ready` 返回503，恢复后无需重启自动恢复；`/health` 仍只表示进程存活。数据库租约阻止并发执行，但不承诺外部副作用恰好一次。已入队旧任务不自动回收。

验证：Cron、DAO、Handler、DI、App完整race，真实SQLite值班写入与回滚、205条同时间戳分页、1001集群分页/部分失败替身、重载及停止、历史非法表达式保护；实际健康路由smoke验证未就绪、恢复及存活边界。未连接真实集群。
