# 告警规则构造合同

保存与生成共用 BuildAlertingRule，按固定 Prometheus v0.311.3 的真实解析/模板实现验证，不执行查询。告警名称是标签值，合法UTF-8及花括号保留，不能套用录制规则的指标名限制。表达式必须返回即时向量或标量；必填持续时间拒绝无效值，不再把错误输入静默改为5秒，合法0与0s保持。

Labels与annotations都按首个等号切分，保留后续等号、逗号和空值，重复键最后值生效。非法键、保留指标名和错误模板在存储前拒绝。生成器按条目隔离坏历史数据，对完整YAML再次做真实rulefmt解析；同名告警合法，group以正数据库ID形成稳定的alert-rule-ID身份，不再因重复显示名称毒化整份文件。

前端同步使用key=value协议。旧的无等号/逗号条目不自动猜测转换；未修改时原样送到严格保存边界并要求人工修正，明确编辑或删除才改变内容。内部原始标记不传后端，DTO仍为string数组；全空新占位省略，非空key的空值保留为key=。没有数据库自动迁移。

## 首次加载的状态边界

旧group以alert名称命名，新group按数据库ID命名。固定版本Prometheus按file+group name定位旧组并CopyState；新组名变化后不直接继承旧active状态，常规热重载也不会替这次变更自动恢复旧for计时。因此首次实际加载可能重新等待for，firing状态也不保证继承。稳定ID避免未来同名冲突，但本次不提供运行状态迁移或“不停报”承诺，发布窗口应由操作人审核。未连接或重载真实实例。
